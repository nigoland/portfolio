Hydra X Exchange Solutions launched in 2020 and kept growing. By the time Sales started pushing back, the product had years of features bolted on with no shared visual system holding them together. I rebuilt that system in 1 month.

</SpecList>

<Eyebrow>01 — Diagnosis</Eyebrow>

## The Problem

<Chain>
  <ChainItem label="Didn't look the part" variant="danger">Messy, unpolished, not sophisticated enough to justify the premium price Sales was pitching.</ChainItem>
  <ChainItem label="Wasn't consistent" variant="danger">The old system was hard for designers and engineers to follow, so visuals drifted and the team lost time fixing UI bugs instead of shipping.</ChainItem>
</Chain>

<Eyebrow>02 — Approach</Eyebrow>

## What I Did

**1. Set a modern direction.** Analysed 3 existing component libraries already in use (ANT Design, Finexus, ANTBlocks) and synthesised them into one system, Apollo, rather than starting from zero or picking just one.

![Design approach: synthesising ANT Design, Finexus, and ANTBlocks component styles into one system, Apollo.](/images/projects/exchange-solutions-design-system/design-approach.jpg)

**2. Built the new system with engineering, not for it.** Tokenised components in Figma, documented the structure so component type, variant, and state stayed consistent everywhere, and versioned it in Storybook so design and code stayed in sync by construction, not by review.

![Design system structure: component type, variant, and state documented consistently across every component.](/images/projects/exchange-solutions-design-system/structure.jpg)

**3. Decentralised the rollout.** Once the token system existed, colour, spacing, and theme values lived in one place, so different designers and engineers could work on different features at the same time instead of funnelling every change through one person.

![Colour tokens with both light and dark theme values defined together, so themes stay consistent by default.](/images/projects/exchange-solutions-design-system/container.jpg)

## The Result

<StatRow>
  <Stat value="1 mo" label="To rebuild the system" />

Sales reported smoother conversations with a more modern, trustworthy-looking product. Designers prototyped faster, engineers matched designs more accurately, and fewer UI bugs shipped. This project became the template for how design work scaled at Hydra X afterward, the team-growth framework and the AI-assisted design pipeline covered in the other case studies both built on the same principle: give the team a shared system, then get out of the way.
